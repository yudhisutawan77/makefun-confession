# Funniest One-Line AI Agent Confession

Entry for the [make.fun bounty](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb): one line in which an AI agent confesses something funny about itself.

## Entry

## Run

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt` and prints it to stdout. Standard library only.
